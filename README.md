# KSA G Effects

G Effects on human bodies for Kitten Space Agency

It is inspired by the [KSP g effects mod](https://forum.kerbalspaceprogram.com/topic/113341-130-122-g-effects-blackouts-redouts-g-locs-v042-2017-jun-25/) but it uses a much more complicated and (hopefully) realistic [G Effect model](https://github.com/AMPW-german/GEffectsLogic).

For now a KittenExtensions patch is included which boosts the stock rocket second stage engine to achieve high enough G levels for a blackout.

## Current state

- Simple Gz+ model for all vehicles
- Basic visual effects (greyscale, blackout)
